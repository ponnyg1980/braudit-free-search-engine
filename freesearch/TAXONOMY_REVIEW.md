## Step 2 — Activities (this decides the classes)

| The client ticks | What it unlocks |
|---|---|
| We sell our own physical products | Goods classes — the products you brand and sell. |
| We provide services | Service classes for what you do for customers. |
| We sell online / retail other people's goods | Retail and online-shop services sit in class 35. |
| We create software, an app or a platform | Downloadable software is class 9; SaaS and development are 42. |
| We provide training or education | Training, courses and education are class 41. |
| We produce media or content | Entertainment and content production are class 41. |
| We offer medical, beauty or therapeutic services | Treatment services are class 44. |
| We manufacture for others (white label) | Treatment/processing of materials for others is class 40. |
| We license or franchise the brand | Franchising and business assistance sit in class 35. |

**Plus a flag (not an allowance):** "We plan to expand into new areas within 5 years" — adds **no** classes; triggers an intention-to-use warning (SkyKick).

## Step 3 — What the client sees back

**Class N · plain-English name**, its band from real filings (**Essential / Recommended / Worth considering / Optional**), an expandable *"What this class covers"*, and its banded terms — all stored for Audit/Application.

| Recommendation | Meaning |
|---|---|
| **Recommended core protection** | Businesses like yours file it, and you do this. Pre-selected. |
| **Optional add-on** | You do this, but it's less commonly filed. Your call. |
| **Not recommended unless genuinely intended** | Filed by businesses like yours — but you haven't claimed the activity. Never auto-selected. |

## Worked example — the drinks trap, solved by data

**Brewery:**

- Class 32 · Beers & soft drinks (Essential) — **✓ core**
- Class 33 · Alcoholic beverages (Worth considering) — Optional add-on
- Class 43 · Food & drink services, accommodation (Worth considering) — Not recommended unless genuinely intended

**Distillery or spirits brand:**

- Class 33 · Alcoholic beverages (Essential) — **✓ core**
- Class 32 · Beers & soft drinks (Worth considering) — Optional add-on

Class 32 is *beers **and** non-alcoholic*; class 33 is *alcohol except beer*. The data gets brewers to 32 and distillers to 33 on its own — and revealed two things we'd have missed: brewers file 33 (**cider**), and distillers file 32 (**0% ranges**).
